# Absence Ops

Operational efficiency tool for [absence.io](https://absence.io).

**[🚀 Live App](https://sea-ai.github.io/absence-ops/)**

---

### Key Features
- **Batch Labels**: Group-apply or clear labels from timespans in a few clicks.
- **Insightful Stats**: Real-time breakdown of your work hours by label.
- **Unified View**: Aggregates fragmented work blocks into a clean daily summary.
- **Privacy Core**: Credentials stay in your local storage; no server-side tracking.

### Getting Started
1. Get your **Client ID/Secret** from [absence.io](https://app.absence.io) (Integrations -> OAuth).
2. Visit the **[Live App](https://sea-ai.github.io/absence-ops/)**.
3. Login and start managing your hours.
